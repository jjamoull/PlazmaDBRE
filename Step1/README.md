This folder contains all the data and artefacts gathered for Step 1 of the Plazma DBRE:

- **SchemaCrawler folder:** All the data extracted using the SchemaCrawler tool ([https://www.schemacrawler.com/](https://www.schemacrawler.com/)).
  - `command.txt`: The command used to generate the SchemaCrawler report.
  - `plazma-implicit.html`: The schema generated by SchemaCrawler.
  - `schemacrawler_fk.md`: Statistics about the foreign keys detected by SchemaCrawler (recall, precision, etc.).

- **Stats folder:** Artefacts related to the general statistics about Plazma required for Step 1.
  - `fk.dm`: Statistics about the foreign keys in the database.
  - `PlazmaCloc.png`: Results of the CLOC analysis performed on Plazma 1.0.5.
