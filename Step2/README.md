This folder contains all the data and artefacts gathered for Step 2 of the Plazma DBRE:

- **DBAccess folder:** All database accesses identified and stored in a structured format.
  - `SQLInspect`: Database accesses identified using the SQLInspect tool.

- **RawDBStatistics folder:** All raw statistics extracted from the database and stored in a structured format (number of SELECT, INSERT, UPDATE, DELETE statements, etc.).
